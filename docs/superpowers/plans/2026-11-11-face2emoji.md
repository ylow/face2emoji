# face2emoji Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Owner instruction:** implementation subagents run on the Opus model.

**Goal:** A Mac app where photos dragged from Apple Photos get an emoji over every detected face, can be fixed up by hand, and are batch-exported as location-stripped JPEGs.

**Architecture:** All logic lives in a SwiftPM library, `Face2EmojiCore` (placement geometry, image loading, face detection, emoji rendering, export, and the observable `Batch` model with undo), tested with `swift test`. A thin SwiftUI/AppKit app target, generated by `xcodegen`, holds only views, gestures and drag-and-drop. Emoji placements are stored in normalised upright-image coordinates and one glyph-image + one geometry function feed the editor, the filmstrip and the export.

**Tech Stack:** Swift 6, SwiftUI + AppKit, Vision, ImageIO/CoreGraphics/CoreText, Swift Testing (`import Testing`), xcodegen. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-11-face2emoji-design.md`

## Global Constraints

- macOS only; must build with Xcode 27 / Swift 6.4 on macOS 27. Deployment target macOS 15.
- No third-party dependencies. No network access anywhere in the app.
- `Face2EmojiCore` must not import SwiftUI or AppKit views; it may import AppKit only for `UndoManager`/fonts if Foundation/CoreText do not suffice.
- Placement coordinates: `center` is normalised (x ÷ width, y ÷ height) with **origin top-left of the upright image**; `size` is the emoji's square side ÷ image **width**; `rotation` is radians, **positive = clockwise as seen on screen**.
- Export: JPEG, quality `0.9`, original pixel dimensions, upright pixels with orientation tag `1`, source colour profile kept, metadata from an allowlist only (Task 4).
- Nothing in the export folder is ever overwritten.
- Default emoji is `😀` at every launch.
- No zoom/pan, no warning badges, no export prompt for emoji-less photos, no session persistence (spec non-goals).
- Loading, detection and export run off the main thread; at most 4 photos processed concurrently.
- Memory: per photo the batch keeps only a thumbnail (longest side ≤ 320 px). The editor loads one preview (longest side ≤ 2560 px) for the current photo. Full resolution is loaded only while exporting that photo.
- Commands: core tests `swift test`; app build `xcodegen generate && xcodebuild -project Face2Emoji.xcodeproj -scheme Face2Emoji -configuration Debug -derivedDataPath build build`.
- Commit after every task, on the working branch, with the message given in the task.

## Review Focus

Each line is pinned by a test in the task named.

1. **A dropped file that is not a decodable image** (PDF renamed `.jpg`, truncated download): it is skipped, the rest of the drop loads, no crash. → Task 5, `addSkipsUndecodableFiles`.
2. **Same file name twice in one batch, or already in the folder** (Photos libraries are full of `IMG_0001`), plus names like `IMG_1.JPG`, `photo.jpeg`, `scan` (no extension): nothing overwritten, JPEG-family extensions kept as-is. → Task 4, `ExportNamingTests`.
3. **An emoji dragged partly or wholly outside the photo:** export clips it and succeeds. → Task 4, `exportClipsOffImageEmoji`.
4. **A photo removed while its face detection is still running:** the late result is discarded, no crash, no ghost photo. → Task 5, `removeDuringDetectionDiscardsResult`.
5. **Source images that are not 8-bit RGB** (greyscale scans, 16-bit, CMYK): export still produces a valid JPEG, falling back to sRGB when a drawing context cannot be made in the source colour space. → Task 4, `exportsGreyscaleSource`.

```swift
    /// Square image, `side`×`side` px, transparent background, the glyph scaled so its

public enum EmojiRenderer {
```

```swift
public enum ExportNaming {
    /// "IMG_1.HEIC" → "IMG_1.jpg"; "a.JPG", "a.jpeg", "a.jpg" unchanged; "scan" → "scan.jpg".
    public static func outputName(forOriginal name: String) -> String
    /// Returns `name`, or "stem 2.ext", "stem 3.ext"… — the first candidate that is neither in
    /// `taken` (compared case-insensitively) nor an existing file in `folder`. Inserts the result into `taken`.
    public static func uniqueName(_ name: String, in folder: URL, taken: inout Set<String>) -> String
}

public enum Exporter {
    public static let jpegQuality = 0.9
    public static func export(source: URL, placements: [EmojiPlacement], to destination: URL) throws
}

public struct ExportJob: Sendable {
    public var source: URL; public var originalName: String; public var placements: [EmojiPlacement]
    public init(source: URL, originalName: String, placements: [EmojiPlacement])
}
public struct ExportReport: Equatable, Sendable {
    public var written: Int
    public var failed: [String]     // original names, in job order
    public var cancelled: Bool
}
public enum BatchExporter {
    /// Up to 4 jobs at a time. Names are assigned up front, in job order, so the result is deterministic.
    /// `progress` is called on the main actor with the number of jobs finished so far (success or failure).
    /// Cancelling the calling task stops starting new jobs; files already written stay.
    public static func export(_ jobs: [ExportJob], to folder: URL,
                              progress: @MainActor @Sendable (Int) -> Void) async -> ExportReport
}
```

**Metadata allowlist** (everything else, including the whole GPS, IPTC and XMP blocks and Apple maker notes, is dropped):

- EXIF: `DateTimeOriginal`, `DateTimeDigitized`, `OffsetTime`, `OffsetTimeOriginal`, `OffsetTimeDigitized`, `SubsecTimeOriginal`, `SubsecTimeDigitized`, `ExposureTime`, `FNumber`, `ISOSpeedRatings`, `ExposureBiasValue`, `ExposureProgram`, `MeteringMode`, `Flash`, `WhiteBalance`, `FocalLength`, `FocalLenIn35mmFilm`, `LensMake`, `LensModel`, `LensSpecification`
- Top level: orientation = 1. Pixel-dimension fields are written from the output image, not copied.

```swift
public struct PhotoSource: Sendable, Equatable {
    public var url: URL; public var originalName: String
    public init(url: URL, originalName: String)
}

public struct PhotoItem: Identifiable {
    public let id: UUID
    public let source: PhotoSource
    public let pixelSize: CGSize            // upright
    public let thumbnail: CGImage           // longest side ≤ 320
    public var placements: [EmojiPlacement]
    public var isDetecting: Bool
}

@MainActor @Observable
public final class Batch {
    public private(set) var photos: [PhotoItem]
    public var currentPhotoID: PhotoItem.ID?          // setting it clears selectedEmojiID
    public var selectedEmojiID: EmojiPlacement.ID?
    public var defaultEmoji: String                    // starts as EmojiCatalog.defaultEmoji
    public var undoManager: UndoManager?
    public var currentPhoto: PhotoItem? { get }
    public var isBusy: Bool { get }                    // any add() still loading or detecting
    public var exportJobs: [ExportJob] { get }         // photos in order

    public init(detector: any FaceDetecting = VisionFaceDetector())

    /// Appends photos in the order given as each finishes loading; runs detection (on an image with
    /// longest side ≤ 4096) and places `defaultEmoji` — as it is when that detection finishes — on each face.
    /// Undecodable sources are skipped. If nothing was current, the first photo added becomes current.
    /// Returns the number of sources skipped. Not undoable.
    @discardableResult public func add(_ sources: [PhotoSource]) async -> Int

    public func removePhoto(_ id: PhotoItem.ID)                 // undoable; current moves to the next photo, else previous, else nil
    public func addEmoji()                                      // undoable; to current photo, centred, selected
    public func deleteSelectedEmoji()                           // undoable; clears selection
    public func update(_ placement: EmojiPlacement, in photoID: PhotoItem.ID)   // undoable; matches by placement.id; move/resize/replace
    public func selectNextPhoto()
    public func selectPreviousPhoto()
}
```

`addEmoji` size: the median `size` of the current photo's placements, or, if it has none, `0.2 × min(width, height) ÷ width`. Undo action names (shown in the Edit menu): "Add Emoji", "Delete Emoji", "Change Emoji", "Remove Photo". Undo of "Remove Photo" restores the photo at its old index with its placements and makes it current. Detection results arriving late are applied directly and are not undo steps.
